# Threat Intelligence Nexus

Repositorio dedicado a la recopilación, catalogación y referencia de fuentes de inteligencia sobre ciberamenazas (*Cyber Threat Intelligence* - CTI) para la protección de sistemas e investigación defensiva.

## Propósito

El objetivo del proyecto es centralizar fuentes de información técnica que permitan a analistas de seguridad, operadores de SOC, equipos de respuesta a incidentes (CSIRT) e investigadores:

- Conocer y contrastar tácticas, técnicas y procedimientos (TTPs) de actores de amenazas.
- Rastrear vulnerabilidades conocidas y activamente explotadas (CVEs).
- Analizar telemetría de malware, indicadores de compromiso (IOCs) y campañas de ransomware.
- Monitorear servicios de la Dark Web y foros asociados a actividades cibercriminales.

## Fuentes de Información

Toda la información referenciada en este repositorio proviene de **fuentes abiertas (*OSINT*)**, marcos estandarizados (como MITRE ATT&CK y CVE Project) y repositorios públicos de investigadores y organizaciones de ciberseguridad.

Para consultar el detalle completo de cada fuente, su alcance técnico y el tipo de datos que provee, consulte:
